BASTION VAULT 0.7 PRO — обновление от 0.6 PRO

1. Автоблокировка: 1, 5, 15 минут бездействия или только при сворачивании. При сворачивании сейф всегда блокируется. Настройка времени хранится локально отдельно от сейфа.
2. Избранное: звёздочка на каждой записи, фильтр «Только избранное», избранные записи выше остальных. Признак избранного хранится внутри зашифрованного сейфа.
3. Быстрое копирование: кнопка @ для логина и кнопка копирования пароля в списке. Скопированные значения попадают в системный буфер обмена — не забывайте очищать его.
4. История: даты создания и последнего изменения записи при открытии редактора. Старые значения паролей не сохраняются.

Сохранены: схема шифрования AES-256-GCM, имя IndexedDB, ключ локальной настройки Face ID/WebAuthn PRF, импорт/экспорт зашифрованной копии и прежние записи. Код не проходил независимый аудит.

ВАЖНО: сначала экспортируйте резервную копию из работающего приложения. Не удаляйте PWA с главного экрана iPhone и не очищайте данные браузера. Загружайте в GitHub файлы из архива по одному или группой, затем проверяйте Face ID и записи. Не загружайте резервную копию, мастер-пароль или реальные пароли в GitHub.
