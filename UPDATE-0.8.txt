BASTION VAULT 0.8 TITAN PROTOCOL — тестовое обновление версии 0.7 PRO

НОВОЕ
• AUTH: TOTP (RFC 6238), 6/8 цифр, SHA-1/SHA-256/SHA-512, период из настроек, обратный отсчёт, копирование, локальное шифрование и необязательная привязка к записи сейфа. Резервная копия включает секреты TOTP. При удалении записи пароля код остаётся самостоятельным.
• QR: локальное чтение чистых обрезанных QR-кодов (версии 1–20, без исправления ошибок, с проверкой контрольных символов); камера через BarcodeDetector только на поддерживаемых браузерах. На iPhone используй обрезанный скриншот или ключ настройки вручную. Если выбор фото блокирует сейф, используй ручной ввод. После настройки удали скриншот QR, включая «Недавно удалённые». Коды Google Authenticator transfer и HOTP не поддерживаются.
• BIO: сохранён прежний WebAuthn PRF-конфиг; быстрый вход вызывает запрос WebAuthn до первого await. Повторное подтверждение биометрией или мастер-паролем для экспорта и открытия окна смены мастер-пароля. Face ID/Touch ID/код устройства выбирает ОС. Touch ID физически отсутствует на iPhone 17. PRF доступен не в каждом браузере. Проверка реальной биометрии на устройстве обязательна.
• CONNECT: инструкции и ссылки на официальные сервисы Google, Instagram, VK, Telegram, GitHub и Apple Account, подсчёт локальных связанных записей. Не синхронизирует данные с сервисами, не читает чужие приложения, не меняет пароль на сайте и не подтверждает состояние защиты. Telegram и Apple не используют обычные TOTP-коды для входа. Для VK наличие TOTP зависит от варианта настроек аккаунта.
• PILOT: пошаговое подключение 2FA с подсветкой полей, мастер создания записи, подсветка настроек экспорта, биометрии и автоблокировки. Внешние приложения не управляются. Новые модули на русском, прежняя локализация сохранена частично.

УСТАНОВКА С IPHONE
1. В старом приложении открой Настройки → Экспорт зашифрованной копии. Сохрани в Файлы; не загружай копию и мастер-пароль в GitHub. Не удаляй приложение и не очищай данные Safari.
2. Распакуй ZIP в Файлах. На GitHub открой прежний репозиторий bastion-vault, ветка main. Add file → Upload files. Выбери одновременно все файлы новой сборки (не ZIP). Commit changes. Сохрани прежний адрес, имя IndexedDB, manifest/start_url, origin и путь приложения.
3. После завершения публикации GitHub Pages открой прежний BASTION, закрой и повторно открой его при необходимости. Проверь подпись v0.8 TITAN. Если не обновилось — подожди публикации; не сбрасывай данные.
4. Проверь старые записи, мастер-пароль, быстрый вход и экспорт. Затем проверь AUTH/PILOT на тестовом ключе (например JBSWY3DPEHPK3PXP), не используй важные аккаунты первым делом.
5. Не откатывайся на 0.7 после добавления 2FA без новой резервной копии: старый код не показывает 2FA и не гарантирует сохранение новой функциональности.

ПРОВЕРКИ И ОГРАНИЧЕНИЯ
Пройдены: Node.js syntax checks; тест RFC 6238 SHA-1 (59 сек., 94287082); локальный тест QR TOTP из чистой картинки; AES-GCM/PBKDF2 шифрование и расшифровка старой схемы и расширенной схемы; соответствие ID интерфейса. Полный браузерный прогон не выполнен (ERR_BLOCKED_BY_ADMINISTRATOR). Реальное обновление IndexedDB, WebAuthn/PRF, Face ID/Touch ID, камеру и офлайн service worker нужно проверить на целевом устройстве. Независимый аудит не проводился. Не храните здесь единственные копии важных учётных данных. Хранить пароль и 2FA вместе менее безопасно, чем раздельно. Старые незашифрованные QR-скриншоты и системный буфер обмена не контролируются сейфом.
