BASTION VAULT 0.9 INFINITY — обновление 0.8 TITAN

УСТАНОВКА (iPhone, без компьютера)
1. В текущем BASTION: Настройки → Экспорт зашифрованной копии. Сохрани файл отдельно от исходников и запомни мастер-пароль. Не отправляй копию в GitHub или чат.
2. Распакуй ZIP в «Файлы». Загрузи исходники в тот же репозиторий и в ту же папку, что раньше. Не удаляй приложение и не меняй URL. В ZIP нет пользовательских паролей.
3. После публикации открой BASTION при наличии интернета. Если осталась старая версия, полностью закрой приложение и открой снова. Проверь подпись v0.9 INFINITY.
4. Проверь прежние записи, мастер-пароль, Face ID и 2FA. Не очищай данные браузера. При проблеме верни предыдущие файлы; резервная копия — дополнительная страховка.

ONE: Сейф → Войти у записи. Открой сохранённый сайт, скопируй логин, пароль и связанный код 2FA по очереди. После входа вернись и отметь завершение. Хранится зашифрованный прогресс последнего входа. Не системное автозаполнение; BASTION не видит действия на другом сайте. Буфер обмена не защищён от других приложений.
DNA: Настройки → Связи аккаунтов. Выбери запись, введи проверенные почту/номер восстановления или провайдера входа, сохрани. Группы строятся из введённых данных, без доступа к аккаунтам. Связь с конкретной учётной записью провайдера не проверяется.
MIGRATION: Настройки → Импорт CSV. Экспортируй CSV из прежнего менеджера, выбери его, проверь счётчики, добавь. Поддерживаются распространённые заголовки CSV (Apple, Google, Bitwarden, 1Password, KeePass); только логины/пароли с допустимыми полями, некоторые экспортированные TOTP. Не все форматы и типы записей поддерживаются; HTTP/нестандартные URI, конфликтующие строки, слишком длинные поля и нераспознанные коды пропускаются. Не загружай CSV в чат/репозиторий. Удали незашифрованный файл и очисти «Недавно удалённые» после проверки. Старые записи не перезаписываются.
TELEPORT: На старом устройстве Настройки → Перенос сейфа → Создать файл → повторная проверка личности → сохранить файл. Передай файл, например AirDrop, и отдельно покажи QR/48-символьный код. На новом устройстве создай сейф, открой Перенос, выбери файл, введи код вручную или прочитай QR с фотографии, подтверди добавление. В пустом сейфе переносятся записи, 2FA и метаданные; в заполненном — новые записи, конфликты пропускаются. Мастер-пароль и биометрия нового сейфа сохраняются. Не передавай QR и файл вместе, не сохраняй QR в общих альбомах. Удали временные копии после проверки. Код не имеет срока действия; это не синхронизация и не прямой сетевой обмен. При сворачивании сейф блокируется, незавершённые операции нужно начать заново. Если системный выбор файла блокирует PWA, повтори после входа; не отключай защиту ради импорта.
IMMORTAL: Настройки → Проверить копию → выбрать файл → ввести мастер-пароль копии → Проверить. Проверка AES-GCM, структуры записей и совпадений основных полей и 2FA с текущим сейфом. Никаких записей в базу; старая копия может быть корректной, но не актуальной. Это не тест восстановления на другом устройстве.
AUTOFILL: Раздел содержит честное объяснение и альтернативу ONE. Системное автозаполнение BASTION ещё не реализовано. Для iOS нужен нативный host app + Credential Provider Extension, entitlement для обоих, защищённый доступ к зашифрованному хранилищу и проверка идентификатора сайта. PWA не может предоставить пароли системному AutoFill. Apple Passwords можно использовать отдельно, без синхронизации с BASTION. Документация: https://developer.apple.com/documentation/authenticationservices/ascredentialproviderviewcontroller/

СОВМЕСТИМОСТЬ И БЕЗОПАСНОСТЬ
Сохранены имя базы IndexedDB, ключ записи, schema=1, version=1, PBKDF2-SHA256 600000 итераций, AES-256-GCM и прежний ключ конфигурации WebAuthn. Новые метаданные находятся внутри зашифрованного сейфа. Нет внешних API, аналитики и серверной синхронизации. QR-генератор локальный, лицензии приложены. Новые экраны на русском; английская локализация новых модулей неполная. Прототип не проходил независимый аудит безопасности. Не используй для критически важных аккаунтов без независимой проверки и резервных копий.

ТЕСТЫ В СРЕДЕ РАЗРАБОТКИ
- node --check: app.js, qr-encode.js, sw.js.
- CSV с кавычками, переносами строк, 2FA, пропуском недопустимого URL; повторный импорт и конфликт без перезаписи.
- Старый формат сейфа; шифрование и расшифровка с новыми метаданными; неверный ключ отклонён.
- RFC6238 контрольный код TOTP.
- QR ключа переноса прочитан независимым декодером OpenCV.
- Уникальные HTML ID; все буквальные ссылки на элементы найдены.
- Полный браузерный тест не выполнен (ERR_BLOCKED_BY_ADMINISTRATOR при загрузке страницы). Реальные CSV разных версий менеджеров, PWA-файловый диалог, Face ID, системный буфер, AirDrop, обновление кэша и перенос между телефонами нужно проверить на устройстве. Это не гарантия отсутствия ошибок.
